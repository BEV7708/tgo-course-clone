# Лабораторная 1. Биграммная языковая модель

Автотестов по этой работе нет, она проверяется по README и устно.

## Источник текста
Роман Ф. М. Достоевского «Идиот»: [Royallib](https://royallib.com/get/txt/dostoevskiy_fedor/idiot.zip)

Файл в репозиторий не кладётся — скачать и положить рядом с ноутбуком как
`Достоевский Федор. ИДИОТ.txt` (кодировка CP1251).

## Что сделано

Привели текст к нижнему регистру.
Полностью удалены знаки препинания регулярным выражением: как отдельные токены они
увеличивают словарь и дают веса для знаков, которые слабо предсказывают
следующее слово.

Текст длиной: **206 572** слова \
Уникальных слов: **27 095**\
Топ-20 слов:
`и (9831), не (5029), в (4795), что (4371), я (3399), с (2568), он (2522), на (2451),
как (1817), но (1765), это (1680), а (1581), вы (1533), князь (1513), все (1506),
же (1396), так (1328), его (1319), к (1154), бы (1083)`.

Последние 10 % текста отложили как тест,
обучение идёт на 185 914 словах.

Написан класс `BigramModel` с методами:
- `fit` — обучение (счётчики слов и пар);
- `prob(v, w) = c(v, w) / c(v)` — вероятность биграммы;
- `generate` — генерация с температурой;
- `logprob` — правдоподобие текста.

## Что получилось

**T = 0.5 (низкая):** модель выбирает только самые предсказуемые слова, текст зацикливается.
**T = 1.0 (норма):** локально слова связаны неплохо, чувствуется авторский стиль, но общего смысла фраз нет.
**T = 2.0 (высокая):** полный хаос — вероятности выравниваются, модель собирает случайные редкие слова.

Без сглаживания модель ломается на первой же незнакомой паре слов из теста. Её вероятность
становится 0, а логарифм правдоподобия — бесконечным. Один случайный пропуск обнуляет оценку
всего текста, поэтому сравнить связный текст с перемешанным без сглаживания физически невозможно.

Со сглаживанием (α = 0.1) модель успешно видит разницу:
* **Связный текст:** −153.37 (вероятность выше, модель узнаёт знакомые переходы)
* **Перемешанный текст:** −172.30 (вероятность ниже, порядок слов противоестественен)

Перплексия на отложенных 10 % теста:

| Значение α | Перплексия (PPL) |
| :--- |:-----------------|
| α = 1.0 | 9494.26          |
| α = 0.1 | 4634.20          |
| **α = 0.01** | **3277.51**      |

Вывод: меньшее сглаживание (α = 0.01) даёт лучшую перплексию. Слишком большой α (например, 1.0)
искусственно переносит много вероятностной массы на несуществующие биграммы — модель начинает
«верить» в шум, штрафует реальные контексты и хуже предсказывает текст.

## Что не получилось и почему
- **Низкая связность генерации:** биграмма помнит только одно предыдущее слово — этого мало
  для синтаксиса и темы, текст распадается на локально правдоподобные обрывки.
- **Разреженность:** многие пары из теста не встречались в обучении; без сглаживания это `-inf`,
  а со сглаживанием невиденные пары всё равно оцениваются грубо.
- **Нет маркеров границ предложений:** модель «перетекает» из предложения в предложение
  (осознанное упрощение в рамках задания).
- **Регистр и пунктуация отброшены:** модель не различает имена собственные и не расставляет знаки.
